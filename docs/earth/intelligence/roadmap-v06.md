# Earth Intelligence v0.6 roadmap

v0.5 establishes a deliberately local foundation. Broader capability follows
measured acceptance, not a claim that a universal production agent is finished.

1. **Stable identity and policy.** Separate owner identity from token hash,
   support credential rotation, scoped grants and revocation, encrypted storage
   policy, authenticated cross-device continuity and audited multi-user isolation.
   This is a prerequisite for any hosted/private coding service.
2. **Portable sandbox.** Isolated mounts/VM or container boundary, hard memory/CPU
   and process limits, reviewed network broker and Windows equivalent. Demonstrate
   exploit/escape negatives before supporting hostile repositories or arbitrary
   test frameworks. Keep shell and unattended writes disabled until justified.
3. **Provider conformance.** Add only independently verified adapters, initially
   a loopback OpenAI-compatible/Hermon adapter if available. Run shared streaming,
   cancellation, redirects, locality, tool semantics and usage tests. Explicit
   privacy/cost approval precedes any cloud adapter; no silent fallback.
4. **Spatial interaction.** Richer source-backed place resolution, clarification
   for ambiguity, saved analysis diffs, temporal workspace views, plan/receipt
   before-after review and application subscriptions. Keep Node/core as authority.
5. **Coding usefulness.** Reviewed multi-file patches with transaction/rollback
   semantics, narrowly typed test adapters and inspectable failures. Never infer
   a shell command from model prose. Maintain explicit artifact context selection.
6. **Operational hardening.** OTLP export from existing tracing spans, retention
   and backups tests over longer runs, crash-injection at mutation boundaries,
   signed native packages and larger measured concurrency/latency/device runs.
   Publish a threat model and independent review before public AI exposure.
7. **Future world link.** Design a capability adapter for MutSea/Finalverse World
   actions with previews, approval and WorldLine receipts. Implement only after
   explicit authorization and service-specific acceptance; the viewer and world
   are not dependencies of Earth Intelligence v0.5.

Success is an observed, permissioned path from human intent to reproducible
spatial or engineering results, across interfaces, with provenance and clear
authority. Marketplace, commerce, autonomous multi-agent fleets, native avatars
and paid public inference remain separate product milestones.
