# Optional MutSea adapter

Enable with `npm run earth:start -- --mutsea`. The registry contains only five existing public operator destinations: Finalverse Harbor, Confluence, Lake House, Conference Center and Autumn Castle. The prior world-library verification date is 2026-10-18; Earth reports current availability as **unverified**, not online. No private worlds, users, inventory, sessions or physical locations are fetched.

All five are fictional. Each carries `geo_anchor:null`; none is drawn at a fabricated place on the planet. Account portal links are usable separately from Earth. Native `secondlife://grid.mutsea.com/secondlife/...` URIs are exposed as integration references in the optional API but are not launched automatically. A native end-to-end handoff check remains required before presenting a “Teleport” button in this browser UI. Installing Earth does not create a world account.

MutSea remains authoritative for identity, world permissions, persistent entities, assets, appearance, transactions and WorldLine. Earth owns geographic analysis and rendering. Future real-place anchors require explicit owner consent, declared CRS/vertical datum, versioned transforms, private/approximate/public visibility and revocation. The tested GeoAnchor utility is not a deployed location-publishing service.

Creator Save/Remix/Publish and market permissions remain in their existing services. Earth does not duplicate them, change licenses or grant resale rights. Living Posts, geographic communities, multi-user overlays and spatial world provisioning are planned separately after the independent core is accepted.
