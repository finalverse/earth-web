Ten new platform/SDK/package tests pass; 40 embedded regressions pass. The browser gate initially exposed the extracted Fetch receiver issue and stale raw-module caching. The SDK now binds the default Fetch receiver correctly, has a regression test, and development serving uses no-store without changing production asset caching.

`benchmark-v04a.json`: one local Node 24.22.0 ARM64 workload, 20 warmups and 100 core/storage samples (1,000 SDK initialization samples). Median spatial/temporal/SDK initialization times are approximately 1.58 / 0.61 / 0.0014 ms. Storage uses an in-memory adapter. These are not browser FPS, disk durability, HTTP throughput or a controlled improvement/SLA claim.

Security review scope: deny-by-default server installation, all referenced dataset IDs, read-only tool classes, source/core permissions, pagination, bounded requests/responses/retries, correlation, same-origin hosting and workspace credential exclusion. Remaining risks include trusted same-origin code, limited device/load coverage and no independent penetration test. No private dataset or credential was published. Rust/framework adapters are deferred for lack of a measured need.

CI evidence: [all four jobs passed for foundation commit cfad05d](https://github.com/finalverse/finalverse-earth/actions/runs/39237212272). v0.4B began only after this result.
