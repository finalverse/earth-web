# Milestone queue

**Now: Earth Core v0.1.** Independent startup, one licensed dataset, shared visual/headless tools, provenance, explicit CRS, one constrained local-model plan, SDK example, bounded contracts and measured verification. Keep this a local experimental developer build until all acceptance checks are recorded.

Next: strengthen dataset schemas/ingestion budgets and authoritative spatial operations, add a spatial index only when measured, support a second approved dataset with an explicit temporal model, and evaluate richer typed plans against reproducible ground truth. Remote/multi-user authentication, application authorization, larger workloads and a supported public deployment need separate threat-model and load gates.

Later, as demonstrated demand warrants: space-time playback/change detection; semantic spatial knowledge; digital-twin adapters; collaborative human/agent workspaces; distributed computation; platform beta. No committed dates, fictional usage metrics or industry solution claims.

Existing Finalverse queue remains open: native Confluence conversation, world-layout planning and WorldLine before/after review within the scene; packaged viewer connection/fresh-install acceptance; art/onboarding/lighting/LOD/performance hardening. These have not become implemented features merely because Earth supplies a geographic prototype. No existing production database, login or renderer is replaced by this milestone.
