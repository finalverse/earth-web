# FSIP 0.1

Finalverse Spatial Intelligence Protocol is an application contract, not a new
renderer, transport, simulator database or LLM-vendor API.

The Rust wire types are in `earth/intelligence/src/fsip.rs`. The schema is
generated by `fsip-schema`; `build.mjs` derives the TypeScript bindings in
`packages/fsip/src/index.ts`. Protocol version 0.1 is a wire literal. Unknown
fields and operation types fail structural validation. Numeric/UUID/date formats
are checked in the schema tests; mutation-specific semantics also require the
Rust manifest validator and the independent native adapter. A valid JSON shape
alone never authorizes an operation.

The initial mutation profile supports only small original approved-asset places:
schematic source-backed exhibitions and purely virtual layouts. It does not
implement arbitrary geospatial reconstruction, executable plans, downloads,
scripts, commerce or general scene authority. `SpatialSession`, `SpatialContext`,
`SpatialArtifact`, `SpatialIntent`, `SpatialPlan`, `SpatialGrant`,
`SpatialExecution`, `SpatialReceipt`, `WorldBinding` and `SpatialPresence` are
versioned vocabulary; existing v0.5 session events remain compatible.

Manifest/workspace hashes refer to the intelligence authority's normalized
compact JSON serialization. Clients should retain the authoritative hash/wire
artifact, not infer equivalence by hashing a pretty-printed or reserialized
document. Native transport checks the exact returned manifest bytes before
preparing a place. Receipts are trusted private-channel execution records, not
publicly verifiable cryptographic signatures.

The JSON fixture uses synthetic/redacted identities. It is an interoperability
fixture, not an importable authority or a signed source receipt. Real model,
PostgreSQL, native UDP and viewer evidence is tracked separately in the
[v0.6 acceptance ledger](../../docs/earth/bridge-v06/acceptance.md).

Read the [integration guide](../../docs/earth/bridge-v06/developer-guide.md) for
handoff ownership, scopes, expiry/revocation, coordinate conventions and recovery.
